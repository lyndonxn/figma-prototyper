# 01 — 产品范围

## 问题与用户结果

官方 Figma MCP 写入画布需要付费 Full seat，且不支持上传图片、自定义字体受限。本项目用"Agent + 本地桥接 + 自定义插件"直接调用免费可用的官方 Plugin API，达成同等能力：AI 在免费版 Figma 上产出**可编辑、可点击**的原型（多方案、组件化、交互已连线），人只负责定方向、选方案、手动微调。

## 角色与权限

| 角色 | 权限 |
|---|---|
| 用户 | 唯一决策人：给目标/规范/目标文件，选方案，Present 模式验收交互；持 Figma 免费账号 |
| Agent（ZCode 等） | 读设计、出方案、生成操作脚本、看截图迭代；**不**做方案取舍决策 |
| 桥接 | 本地任务管道：鉴权、队列、消息转发；不做任何智能处理 |
| 插件 | 在 Figma 画布内执行脚本、导出截图、（M2 起）上报画布事件 |
| Figma 桌面端 | 宿主：须保持运行、插件保持活动 |

## 范围内（M1–M5 原型链路；M6 起 Design→Code）

插件骨架 → WebSocket 双工桥接 + 暂停开关 → CLI + 截图闭环 → 文字/图片/组件/字体 → 原型交互 + 流程固化成 Skill。验收 ID 见 `05-acceptance.md`。

**M6 Design→Code（2026-09-22 新增，用户决策）**：经设计 IR 中枢，把 Figma 画板抽取为 `design-ir.json`，Agent 据此合成 **HTML+CSS 单文件静态页**，并用系统 Chrome headless 截图与 Figma exportAsync 截图做视觉对比闭环。边界：只做单方向（Code→Design 预留 M7 候选）；目标形态为静态页，不含构建链。

## 范围外（非目标）

- **App 客户端 ↔ Figma 双向实时同步**（共享数据源级别的单向可后续评估；完整双向映射明确不做）。与 M6 的边界：M6 是**离线批量转换**（人显式发起、无运行时双写），不触碰本非目标
- 插件上架 Figma Community、商业化
- 云端服务/远程桥接（仅 127.0.0.1）
- 多人协作/多 Agent 并行写画布场景
- 工程级前端代码生成：框架组件（React/Vue 等）、构建工具链、工程化产出仍不做（静态 HTML+CSS 单文件自 M6 起属于范围内）

## 用户故事

1. 作为用户，我说出设计目标 + 现有规范 + 目标文件，Agent 产出 ≥2 套可编辑、可点击的候选方案，我直接在 Figma 里点着比较。
2. 作为用户，我在画布上手动修改时 Agent 能感知并让步（暂停），不与我的操作打架。
3. 作为用户，整个过程我不用订阅任何 Figma 付费席位。
4. 作为用户，我把设计好的画板链接交给 Agent，得到一份结构等价的静态 HTML+CSS 页面（M6），可直接在浏览器打开、继续手工编辑。
