# ADR-0002 — Token 成本控制内置为验收约束

日期：2026-09-19 ｜ 状态：已接受 ｜ 影响：M3/M4 验收 ID、Agent 工作流

## 背景

系统总成本 ≈ 迭代轮数 ×（一张截图 + 一份脚本）+ 随轮数增长的上下文。截图是视觉 token 大头；上下文无界增长是隐性放大器。事后优化无法约束 Agent 行为。

## 决策

把成本控制写成**硬性验收条目**而非建议（`spec/05` FUN-ACC-303、FUN-ACC-404）：

1. 截图导出强制支持区域裁剪 + 缩放倍数，禁止默认整页高清；
2. 脚本必须批量操作，验收以轮数最小化为准绳；
3. 节点树/设计读取强制过滤（深度 + 字段白名单）；
4. 上下文分阶段落盘（本工作区 HANDOFF 协议），新会话续接。

## 后果

- 正向：每轮迭代成本有上界；长任务可跨会话续接。
- 代价：实现时多一层参数设计（导出/读取 API 均需带过滤参数）。
